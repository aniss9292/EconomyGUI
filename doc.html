EconomyGUI

A shop and sell GUI for legacy PocketMine-MP servers. Double-chest interface, paginated categories, sell hand / all / undo, and optional integration with SmartSpawner and AzCustomEnchant.

install

Installation

  1. Place the EconomyGUI folder in plugins/
  2. Restart the server
  3. Three files auto-generate: config.yml, shop.yml, sell.yml
  4. Edit prices and categories as needed
  5. Run /shopreload to apply changes without restarting
Requires EconomyAPI. SmartSpawner and AzCustomEnchant are optional soft-dependencies — their shop categories hide automatically if either is missing.

player guide

Using the shop

Open /shop to see categories. Click a category to browse items, click an item to open the buy screen, then pick 1x, 10x, or 64x.

The back button sits at slot 45. Yellow and blue wool buttons flip between pages.

01 · browse

Pick a category, scroll pages with the wool buttons.

02 · buy

Click an item, choose a quantity, confirm.

player guide

Selling items

Sell chest — open /sell, drop items inside, close the chest. Sellable items are sold instantly, the rest come back to you.

Sell hand — /sell hand sells whatever you're holding.

Sell all — /sell all scans your whole inventory and sells everything sellable at once.

Undo — /sell undo reverses your last sell if you still have enough money and space, within the server's time limit.

config.yml

Server configuration

Controls GUI titles, currency symbol, cooldowns, sounds, logging, undo time, and buy-button layout.

shop-title: "§l§6» §r§eShop §l§6«"
sell-title: "§l§2» §r§aSell Chest §l§2«"
currency-symbol: "$"
purchase-cooldown: 0
log-transactions: true
undo-time-limit: 300

sounds:
  enabled: true
  on-purchase: "random.orb"
  on-sell: "random.orb"
  on-error: "mob.villager.no"

Messages support placeholders: {amount} {item} {symbol} {price} {balance} {category}.

shop.yml

Optional categories

Spawners — needs SmartSpawner:

spawnerz:
  spawner_types:
    iron_golem:
      items:
        - id: 52
          price: 400000
          spawner_type: iron_golem
          spawner_tier: basic

Custom enchants — needs AzCustomEnchant:

custom_enchants:
  items:
    - id: 403
      name: §r§6Excavator Book
      price: 250000
      enchant_key: excavator
Both categories hide from /shop automatically when their plugin isn't installed.

integrations

SmartSpawner & AzCustomEnchant

smartspawner

Shop entries with spawner_type + spawner_tier call giveSpawnerItem() to hand out a real, correctly-tagged spawner.

azcustomenchant

Shop entries with enchant_key call createEnchantBookItem() to produce a properly tagged enchant book.

Both are soft-dependencies — the plugin loads fine without them, and their categories simply stay hidden.

anti-dupe

How exploits are blocked

  1. NBT marker — every GUI item is tagged economygui_menu_item = 1
  2. Transaction cancellation — clicks inside the GUI are menu actions, never real inventory moves
  3. Multi-event sweep — tagged items are stripped on transaction, close, hotbar switch, drop, interact, and quit
  4. Real item display — items look exactly like what the player receives, safely
On MCPE 0.14.3/0.15.x, client-side prediction can flash a tagged item for a single tick before removal — expected and harmless.
architecture

Under the hood

EconomyGUI/
├── EconomyGUI.php          # main class: commands, events, GUI logic
├── gui/
│   ├── BaseGUI.php         # fake-chest + navigation
│   ├── FakeHolder.php      # virtual InventoryHolder
│   ├── OpenContainerTask.php # delayed open (2-tick)
│   ├── ShopGUI.php
│   └── SellChestGUI.php
└── manager/
    └── ConfigManager.php   # config.yml / shop.yml / sell.yml

The double chest is a fake block: two chest blocks are sent to the client, linked via pairx/pairy/pairz NBT, opened after a 2-tick delay, then restored on close.

player guide

بيع العناصر

صندوق البيع — افتح /sell، ضع العناصر بداخله، أغلق الصندوق. القابلة للبيع تُباع فوراً، والباقي يُعاد لك.

بيع سريع — /sell hand يبيع ما بيدك مباشرة.

بيع الكل — /sell all يفحص كامل الإنفنتوري ويبيع كل شيء قابل للبيع دفعة واحدة.

تراجع — /sell undo يرجّع آخر عملية بيع بشرط توفر المال والمساحة، وضمن الوقت المحدد من السيرفر.

integrations

SmartSpawner و AzCustomEnchant

smartspawner

عناصر المتجر التي فيها spawner_type و spawner_tier تستدعي giveSpawnerItem() لإعطاء سبونر حقيقي بعلامة صحيحة.

azcustomenchant

عناصر المتجر التي فيها enchant_key تستدعي createEnchantBookItem() لإنشاء كتاب سحر بعلامة صحيحة.

كلاهما اعتماديات اختيارية — الإضافة تعمل بدونهما، وتصنيفاتهما تبقى مخفية فقط.

anti-dupe

كيف يتم منع الاستغلال

  1. علامة NBT — كل عنصر داخل الواجهة يُعلَّم بـ economygui_menu_item = 1
  2. إلغاء المعاملات — كل ضغطة داخل الواجهة تُعامل كإجراء قائمة، لا كحركة إنفنتوري حقيقية
  3. تنظيف متعدد الأحداث — العناصر المعلّمة تُزال عند المعاملة، الإغلاق، تغيير السلوت، الإسقاط، التفاعل، والخروج
  4. عرض حقيقي للعنصر — العناصر تظهر تماماً كما سيحصل عليها اللاعب، بأمان
على MCPE 0.14.3/0.15.x قد يظهر العنصر المعلّم للحظة واحدة قبل إزالته — هذا متوقع وغير ضار.
